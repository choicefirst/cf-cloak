## Practical guidelines

- Open an issue before starting significant work — saves everyone time if the direction is wrong.
- Keep PRs focused. One thing per pull request.
- Tests are required for any change to blocking or identification logic.
- Match the existing code style; no reformatting unrelated lines.
- Update the relevant docs if behaviour changes.

---

## What we won't merge

- Anything that degrades user privacy.
- Telemetry, analytics, or any outbound call we haven't explicitly approved.
- Changes that break the AGPLv3 compliance guarantees.
- AI-generated code submitted without manual review and testing.
